# Shogi Lab

本地双人将棋变体实验室，包含 5×5 BP 大将棋与 9×9 Chess vs Shogi。无需账户、服务器数据库或安装依赖。

## lishogi 界面适配（2026-10-09）

保留现有 5×5 BP 引擎，改为 lishogi 浅色对局布局。实际复用官方木纹、Ryoko SVG 棋子与棋谱 CSS；具体文件、提交和许可证见 [SOURCES.md](SOURCES.md)。这不是完整 lishogi 服务端，也没有联网匹配、标准 9×9 规则或 AI。

入口仍为 `index.html`。适配样式为 `src/lishogi.css`，上游资源及原 SCSS 在 `vendor/lishogi/`，旧界面备份在 `src/legacy/`。完整可下载源码为 `source.zip`；修改后可运行 `python3 scripts/package_source.py` 更新它。

## 主界面与动画图鉴

- `/#home`：实验室介绍、创作缘起与可左右拖动的动画棋子卡组；支持方向键和切换按钮。
- `/#library`：可搜索图鉴，鼠标悬停或键盘聚焦出现动画浮窗；点击进入独立详情。按模式、阵营、升变前后筛选；单击立即进入详情，独立按钮翻面。
- `/#piece/drunken-elephant`：棋子详情示例，可直接访问、刷新、前进和后退。展示本体与升变走法、翻面升变动画、暂停与重播。
- `/#game`：原有 BP / 布阵 / 对局页面。
- `/#history`：多局历史，包含未完成对局。
- `/#match/<id>`：逐步回看禁选、布阵与行棋，支持棋谱导出。

动画由 `src/study.js` 使用现有规则引擎生成，无阻挡示意不会改变棋局。无法从中央演示的长距离跳跃改用可行起点；未知特殊走法不生成猜测动画。系统开启“减少动态效果”时，动画默认暂停，用户仍可主动播放。

## 运行

安装 Node.js 20 或更新版本后，在此目录执行：

```sh
node server.mjs
```

打开 <http://localhost:5173>。也可使用 `npm run dev`。服务仅监听本机地址。

当前这台 Mac 没有全局 Node，可以双击 `start.command`，它会使用已有的 Codex Node 运行时。

## 已实现

- 从 173 种本体和升变都可执行的棋子中，按种子无放回抽取 16 枚。
- 新局只选不禁，顺序 ABBAABBAAB；旧存档继续原禁选规则。
- 每方固定王将 + 五枚所选棋子，在己方两排轮流公开布阵。BP 王将采用标准八方向一格走法。选阵短按选取、长按预览；布阵拖动显示落位虚影与走法。
- 合法落点、双方朝向、阻挡、跳跃、吃子、首次吃子升变（每枚一次）、王与太子共同胜负判定。
- 图鉴、中文走法、升变预览、翻转棋盘、自动保存、撤销、协议和棋、认输、JSON 棋谱导出。
- 无依赖的 JavaScript 规则引擎，可独立于 UI 扩展。

## 范围和约定

这是 **5×5 改编原型，并非完整大局将棋模拟器**。目录有 209 条本体记录及相应升变记录，包含来源所列左右变体、异名。可执行不等于已经逐枚人工考据；简单走法由资料的 Betza 表达编译，已抽样对照文字与图示。来源有歧义的高级走法默认不入池。狮子的多段移动/居食、钩行转向、贯穿吃子、部分跳后续行还未实现。有关本体或其升变依赖这些走法的棋子不会进入 BP。

不限制王进入受攻击位置，以吃掉全部王族判胜；无打入。5×5、随机 16 枚、五选加王、己方两排布阵、无着法判负是本原型约定。没有添加技能、经济、生命值或属性系统。未加入联网、AI、计时、三次重复自动判和；可协议和棋。公开布阵可能产生立即吃王的开局，这是当前规则允许的情况，平衡性有待实玩验证。

本地存档仅保存在当前浏览器。旧版单局存档自动迁入对战历史；新局拥有独立 ID，同种子不会覆盖旧局。每步保存局面与历史，刷新可继续。回看页支持逐步浏览与 JSON 导出，暂不支持导入。历史使用浏览器存储容量，写入失败会提示，不会自动删除旧局。

- 混合模式独立采用标准将棋走法，王将一格。支持王安全、将军/将死、将棋可选/强制升变、二步/死位/打步诘限制、兵初始两步/斜吃/吃过路兵、王车易位、四种国象升变。

- 未结束对局可从历史回看页继续。新模式共用历史存档，旧棋局不覆盖。

## 2026-10-18：双王与棋盘交互

新建 Chess vs Shogi 为 v3「吃王制」：国象后排车、马、象、王、后、王、象、马、车，九个兵；两个王全部被吃才输，将棋王被吃即输。将军只提示、不限制普通行棋，无合法走法判负；王不进入持驹。旧版单王存档继续原将死制。双王分别向各自外侧车易位，两格移动，仍禁止经过攻击格。

支持棋盘鼠标/触摸拖动、持驹拖入、非法落点回位；点击走棋保留。升变改为落点附近浮条，选择前不写入存档，取消或 Escape 返回原局面。持驹使用木质方形驹台，同种棋子堆叠并显示数量。棋盘在第四/第五行边界切换材质，不再截断半个格子；统一格子的宽高与边线。控制按钮改为 pill，提供 hover、focus 与按下反馈。

### 对局界面与计时

创建对局弹窗可切换变体、实时/无时限、每方时间与读秒，并选择本地视角。实时局使用单次读秒：基本时间耗尽后，每步重新获得所设秒数；时间在离开页面或刷新后继续计算。BP 在布阵完成后开始计时。旧存档保持无时限。

棋谱条和左右方向键只回看，不修改存档；回看时禁止走棋，可返回最新局面继续。撤销是独立操作。走子有位移动画（尊重减少动态效果设置），音效按钮可静音。音频按行动方选择：将棋方使用 Lishogi Shogi 音效，国际象棋方使用 Lichess Standard 音效；双方分别使用原始走子与吃子音频。将棋方打入国象棋子仍使用将棋方音效。将棋方持驹显示为淡色占位及数量，支持点击和拖动打入。

### 首局教学

每个模式分别记录首次进入状态（`shogilab-intro-v1-draft` / `shogilab-intro-v1-versus`）。教学采用独立 HTML/CSS 动画棋盘，不操作对局状态；支持上一步、下一步、跳过及 Escape 关闭。模式卡片“玩法演示”和对局顶栏“演示”可重看。实时对局观看期间暂停棋钟，退出恢复；中途刷新会重新打开尚未结束的教学。新禁手仍处于讨论阶段，规则引擎未改动。

### 在线对战（完整单实例后端）

使用 Node 20+ 运行 `node server.mjs`。不需要 npm 依赖、账号服务或外部数据库。创建对局中选“在线邀请”，选择阵营后复制房间链接；对方加入后两人点击准备。两种模式均支持，BP 的选阵和布阵也在服务端校验。可在两个浏览器中验证；同一浏览器的同源标签共享座位凭证，因此自动作为同一玩家重连。

前端每秒拉取服务端快照，断线后自动重试，重复请求具有操作 ID 去重。房间、座位令牌哈希、棋谱、计时写入 `.server-data/`，重启后恢复。在线棋钟由服务器裁决；离开、断线或查看教程不会暂停。无时限房间可通过相同链接继续。在线悔棋需对方明确同意，撤销最近一步但不返还已用时间；新的落子会取消待处理申请。双方和棋需对方明确接受。无注册、无匹配大厅、无积分；采用私密邀请房和匿名昵称。

部署、接口契约和交接约束见 [deploy/README.md](deploy/README.md)。当前本地地址不会让公网好友连入；部署到 HTTPS 域名后原界面即可使用。不要把 `.server-data`、座位令牌或个人存档提交到公开仓库。
